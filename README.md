# my-claude-sidekick

## get started

### claude code

Use command below in claude code to install

``` 
/plugin marketplace add YMoose/my-claude-sidekick
```

### codex

Use command below in codex to install one of the skills. For example [coach-feynman](./coach-feynman/README-zh.md)

``` 
$skill-installer install https://github.com/YMoose/my-claude-sidekick/tree/main/coach-feynman
```
