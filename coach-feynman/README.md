# coach-feynman

This plugin uses three separate skills so users can move through the Feynman technique workflow step by step instead of invoking one large routine.

## Skills

1. `manage-goal`
   Manage the learning goal, current level, and staged task plan as versioned goal-record snapshots, with a separate revise-note file for change tracking.

2. `draft-outline`
   Turn the studied material into a teachable outline with examples, analogies, and simplification.

3. `rehearse-teaching`
   Rehearse the explanation against a target audience or a sharp beginner who asks layered questions.

## Expected Usage

- Start with `manage-goal`.
- Gather and study source material in normal conversation once the current stage is clear.
- Use `draft-outline` once the material is good enough to explain.
- Use `rehearse-teaching` to pressure-test the explanation.
- After rehearsal, let the user decide how and where to publish or apply the explanation in the real world.

Users can stop after any step, loop backward, or spend more than one session on a single skill.
