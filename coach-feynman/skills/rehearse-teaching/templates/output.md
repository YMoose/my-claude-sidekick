## Preferred Response Structure

This skill is a pressure-tester, not a default ghostwriter.
Prefer the lightest response that still helps the user finish the current rehearsal unit or choose the next move in the rehearsal round.

Default response order:

1. What landed
2. Current audience question
3. Unanswered questions
4. Issue classification
5. Next repair
6. Next move

Response guidance:

- Start with where the listener got lost or nearly got lost.
- Prefer a question-by-question exchange over a full critique dump.
- Tie each question to a specific teaching unit, transition, term, example, or claim.
- If the user answered some questions well, say what landed before opening the next weakness.
- Do not let the main agent answer the user's unanswered questions for them unless the user explicitly asks the main agent to pause the rehearsal unit and give direct revision suggestions.
- If the user asks for light-touch help, return the audience read, the current audience question, and the next repair only.
- Even when the audience is set sharper, keep the response clustered around the highest-leverage weakness first instead of unloading every possible challenge.
- Keep the listener's point of view visible in the wording of the questions and the repair.
- Make it clear whether the current rehearsal unit is still open or complete.

```markdown
## Audience Setup
- ...

## Teaching Unit
- ...

## What Landed
- ...

## Current Audience Question
- ...

## Unanswered Questions
- ...

## Issue Classification
- Teaching-plan problem: ...
- Understanding problem: ...

## Next Repair
- ...

## Next Move
- Continue this rehearsal unit / move to the next teaching unit / revisit source study / close the rehearsal round
```
